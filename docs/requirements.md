# 要件定義書

## 1. プロジェクト概要

### 1-1. 目的
子供向けのe-learningサイト。マテリアル（テキストまたはURL）をLLMで読み取り、問題を自動生成する。

### 1-2. ターゲットユーザー
- **子供（学習者）**: 問題を解く、ポイントを稼ぐ、バッジを集める
- **親（管理者）**: 学習状況の確認、ポイント調整、通知設定

---

## 2. 機能要件

### 2-1. 子供用画面

| 機能 | 説明 | 優先度 |
|------|------|--------|
| ログイン | 子供用の簡易ログイン | 高 |
| 学習ダッシュボード | 教科選択、進捗表示 | 高 |
| 問題解答 | LLM生成問題を解く | 高 |
| ポイント表示 | 獲得ポイントの確認 | 高 |
| バッジコレクション | 獲得バッジの一覧表示 | 中 |
| 学習履歴 | 過去の成績確認 | 中 |
| 効果音・アニメーション | 正解/不正解時の演出（軽量） | 低 |

### 2-2. 管理画面（親用）

| 機能 | 説明 | 優先度 |
|------|------|--------|
| ログイン | 親用の認証付きログイン | 高 |
| 学習状況ダッシュボード | 子供の学習進捗を一目で確認 | 高 |
| マテリアル管理 | テキスト/URL登録→問題自動生成 | 高 |
| 問題管理 | 自動生成問題の確認・編集 | 高 |
| ポイント管理 | ポイントの確認・手動調整 | 中 |
| バッジ管理 | バッジの追加・条件設定 | 中 |
| 通知設定 | 問題完了時のメール通知 | 低 |

### 2-3. LLM問題自動生成

| 機能 | 説明 |
|------|------|
| テキスト読み取り | テキストを入力→内容を解析 |
| URL読み取り | URLを入力→ページ内容をスクレイピング→解析 |
| 問題生成 | 解析結果からLLMが問題を自動作成 |
| 問題タイプ | 選択式、○×式、穴埋め、短答式 |
| 難易度設定 | かんたん、ふつう、むずかしい |

### 2-4. ポイントシステム

| ルール | 説明 |
|--------|------|
| 基本ポイント | 正解時に基本ポイントを付与 |
| スピードボーナス | 早く回答するほど追加ポイント |
| 苦手克服ボーナス | 苦手分野をクリアしたら追加ポイント |
| 連続正解ボーナス | 連続正解でボーナスポイント |
| 手動調整 | 親がポイントを手動で加減算 |

※ 細かいポイント計算ロジックは後日詰める

### 2-5. バッジシステム

| バッジ名 | 達成条件 |
|----------|----------|
| はじめの一歩 | 初めて問題に正解 |
| 連続正解マスター | 5問連続正解 |
| がんばり屋さん | 合計50問回答 |
| ポイントハンター | 合計500ポイント獲得 |
| スピードスター | 制限時間の半分以内で正解 |
| 苦手克服 | 苦手分野で3問連続正解 |

※ バッジは後から追加・変更可能

---

## 3. 非機能要件

| 項目 | 内容 |
|------|------|
| レスポンス | 画面遷移は2秒以内 |
| 可用性 | 99%以上（VPS） |
| セキュリティ | パスワードハッシュ化、CSRF対策、XSS対策 |
| スケーラビリティ | 初期は家庭内利用。将来的に複数家庭対応 |
| 多言語 | 日本語のみ（初期） |
